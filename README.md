# USF Capstone Academic ePortfolio

A clean, accessible, multi-page academic ePortfolio for Antonio Fernandez's University of South Florida Information Science capstone course.

## Purpose

The website is designed for:

- University faculty reviewing capstone coursework
- Prospective employers reviewing academic and professional achievements
- Ongoing publication of course artifacts and reflections

This is a separate academic portfolio and is not presented as a cybersecurity project portfolio.

## Pages

- `index.html` - Home and academic overview
- `enhanced-bio.html` - Extended professional biography
- `project-management-plan.html` - Project plan paper placeholder
- `artifacts.html` - Current and future capstone assignments
- `resume.html` - Education, skills, certifications, and career interests
- `contact.html` - Professional contact links

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages compatible
- No frameworks or external dependencies

## Accessibility

- Semantic headings and landmarks
- Keyboard-accessible navigation
- Skip-to-content link
- Strong color contrast
- Readable line length and spacing
- No animation, moving backgrounds, or scrolling effects
- Responsive layouts for desktop, tablet, and mobile
- Print styles for papers and resume content

## Editing Guide

1. Replace all text enclosed in square brackets.
2. Replace the headshot placeholder with an image if desired.
3. Update the contact links in `contact.html`.
4. Add the final resume file and update the download link in `resume.html`.
5. Paste the completed capstone paper into `project-management-plan.html`.
6. Replace future artifact cards as assignments are completed.

## GitHub Pages

Publish the repository from the `main` branch and root directory in the repository's **Settings > Pages** section.
